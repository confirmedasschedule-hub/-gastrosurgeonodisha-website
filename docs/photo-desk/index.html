Gallery photo desk

Private page for updating the website gallery

Open this page with https:// at the start of the address. The photo desk only works on a secure connection.

Website owner:

One-time setup

The website owner does this once. You need a GitHub "key" that lets this page change the gallery, then you choose the password that the photo person will use.

  1. On a computer, log in to GitHub and open github.com/settings/personal-access-tokens/new
  2. Token name: photo desk. Expiration: No expiration (or the longest offered).
  3. Repository access: Only select repositories → choose
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy it (it starts with github_pat_) and paste it below.

The key is stored on the website only in locked (encrypted) form. It can be opened only with the password. To cut off access at any time, delete the token on GitHub.

Add photos, write a short caption, use the arrows to set the order, then press Publish. The website updates about 1–2 minutes later. A caption like Award 2027 / Name of the award shows "Award 2027" as a small red label.
